## 🚀 Featured Project

### ⛏️ [PingMC](https://github.com/EmoooNET/ping-mc)

> A lightweight, **zero-dependency** TypeScript library that queries **Minecraft Java Edition** servers over the classic Server List Ping protocol.

- ✅ Supports Java Edition **1.7+** — ships as **ESM** with full `.d.ts` types
- 🔁 One connection per request, no cache, no polling — `getStatusWithPing()` returns a snapshot *and* latency
- 📦 Currently maintained — not yet published to npm
