## 🚀 精選專案

### ⛏️ [PingMC](https://github.com/EmoooNET/ping-mc)

> 一個輕量、**零依賴**的 TypeScript 函式庫，透過經典的 Server List Ping 協定查詢 **Minecraft Java 版**伺服器狀態。

- ✅ 支援 Java 版 **1.7+** —— 以 **ESM** 形式發布，並附帶完整的 `.d.ts` 型別
- 🔁 每次請求建立一個連線，無快取、無輪詢 —— `getStatusWithPing()` 同時回傳狀態快照與**延遲**
- 📦 持續維護中 —— 尚未發布到 npm

[![PingMC Repo](https://img.shields.io/badge/PingMC-GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/EmoooNET/ping-mc)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Node 22+](https://img.shields.io/badge/Node.js%2022%2B-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)
![pnpm](https://img.shields.io/badge/pnpm-F69220?style=for-the-badge&logo=pnpm&logoColor=white)

### 🔎 [QueryMC](https://github.com/EmoooNET/query-mc)

> 一個**零依賴**的 TypeScript 函式庫，透過 UDP **Query（GameSpy4）**協定查詢 **Minecraft Java 版**伺服器 —— 支援 **Basic Stat** 與 **Full Stat** 兩種模式。

- ✅ 支援 Node.js **22+** —— 以 **ESM** 形式發布，並提供 `.d.ts`、宣告檔映射與原始碼映射
- 📊 回傳 MOTD、版本、線上/最大玩家數、玩家清單、地圖、伺服器軟體與外掛，以及 Stat 往返**延遲**
- 🔁 每次呼叫都會新建一個 UDP 通訊端，無快取、無輪詢、不自動重試 —— 何時重試由呼叫端決定
- 📦 持續維護中 —— 尚未發布到 npm（可在本機用 `pnpm pack` 打包）

[![QueryMC Repo](https://img.shields.io/badge/QueryMC-GitHub-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/EmoooNET/query-mc)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Node 22+](https://img.shields.io/badge/Node.js%2022%2B-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)
![pnpm](https://img.shields.io/badge/pnpm-F69220?style=for-the-badge&logo=pnpm&logoColor=white)

> PingMC 使用遊戲客戶端所用的 **TCP** Server List Ping 協定；QueryMC 使用 **UDP** Query 協定，該協定需要在 `server.properties` 中開啟（`enable-query=true`）。
